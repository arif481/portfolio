## ✨ Features

- 🎨 **Modern Dark Theme** - Clean, professional design with pink accent colors
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop
- 🍔 **Mobile Navigation** - Slide-out hamburger menu for mobile devices
- ⚡ **Smooth Animations** - Scroll animations and hover effects
- 📧 **Working Contact Form** - Integrated with Formspree for email submissions
- ♿ **Accessible** - Skip navigation, ARIA labels, and semantic HTML
- 🔍 **SEO Optimized** - Meta tags, Open Graph, Twitter Cards, sitemap

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, Animations, Media Queries
- **JavaScript (ES6+)** - Intersection Observer, Fetch API, DOM Manipulation
- **Font Awesome 6** - Icons
- **Google Fonts** - Poppins font family
- **Formspree** - Contact form backend
- **GitHub Pages** - Hosting & CI/CD

## 🚀 Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions.

### Manual Setup

1. Fork this repository
2. Go to **Settings** → **Pages**
3. Under "Build and deployment", select **GitHub Actions**
4. Push changes to `main` branch to trigger deployment

## 📋 Sections

1. **Hero** - Introduction with animated text
2. **About** - Bio with Skills/Experience/Education tabs
3. **Services** - Web Development, UI/UX, Responsive Design
4. **Portfolio** - Project showcase with hover overlays
5. **Contact** - Working form, social links, CV download

## 🔧 Customization

To use this template for your own portfolio:

1. Replace images (`logo.png`, `arif.jpeg`, `background.png`)
2. Update content in `index.html`
3. Modify colors in `styles.css` (search for `#ff004f`)
4. Update social links and contact information
5. Add your own resume as `Resume.pdf`
6. Update Formspree form ID in contact section
